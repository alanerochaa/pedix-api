Visão geral

API Java de suporte ao Pedix

Esta API é consumida pelo aplicativo mobile Pedix e disponibiliza funcionalidades relacionadas a cardápio, categorias, avaliações, histórico de pedidos e relatórios administrativos.

O fluxo principal de pedidos, comandas e pagamento fica centralizado na API C#. A API Java atua como camada complementar de suporte, gestão e consulta.
